**what currently exists?**
A full-stack application built with Expo (React Native) and FastAPI. The app allows users to create, manage, and analyze complex decisions using a structured process (PRR).

Key features implemented include:
- A multi-step decision wizard for defining factors, options, classifications, priorities, and assessments.
- User authentication via email/password and Google OAuth.
- A Forgot Password flow and an option for Google users to set a password.
- A template system with four categories (Authorized, My, Shared, Public) and granular sharing options.
- A 3-tier role-based access control system (Super Admin, Co-Admin, Admin) for managing templates.
- Voice input for the assessment step.
- Cloning functionality for decisions.
